{% comment %} Light or dark theme, applied before the page paints. Include it in the , before any stylesheet (index.html and auth_layout.html do). theme_preference (base.context_processors) is the explicit choice from the theme cookie: "dark", "light", or "" to follow the system. While it is "" the page follows prefers-color-scheme, live. The stylesheets key off `dark` on (Tailwind's darkMode: 'class') and on (dark.css), so both get it: the template renders it for an explicit "dark", and the script below covers the system case, adding it to as soon as the parser creates it, before the first paint. Any element with data-theme-toggle switches the theme. The new choice is the opposite of what is shown; when that is what the system would show anyway, the choice is dropped and the page follows the system again. Icons marked .hx-theme-when-light / .hx-theme-when-dark show only in that theme, so a toggle's icon is right on load in every case. It runs once per page: some standalone pages that include it (no_perm, the error pages) are also returned to htmx requests and swapped into a page that already has it, and a second copy would add a second click handler, so every toggle would switch the theme twice. {% endcomment %}
